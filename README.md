# Professional portfolio — Jose de Jesus Castillo

A responsive professional portfolio focused on Cloud Infrastructure, DevOps, and Data Engineering.

## Local preview

Open `index.html` in a browser. No build tools or dependencies are required.

## Deploy with GitHub Pages

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
3. When deployment completes, visit https://josedjc-dev.github.io.
