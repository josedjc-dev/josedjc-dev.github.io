## Project roadmap

This project is **planned, not yet implemented**.

The goal is to build a small, reproducible Azure environment using Terraform, with clear architecture documentation, validation, and an automated deployment workflow.

### Planned milestones

1. Define the target architecture and infrastructure requirements.
2. Write and validate Terraform configurations.
3. Add automated formatting and validation checks.
4. Document deployment, cost considerations, and teardown steps.
5. Publish the working code and results in a dedicated repository.
