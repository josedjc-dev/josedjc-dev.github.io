## Project roadmap

This project is **planned, not yet implemented**.

The goal is to demonstrate a small, testable data pipeline using Python and SQL, with a reproducible sample dataset and clear documentation.

### Planned milestones

1. Select a public or synthetic sample dataset.
2. Implement ingestion and data-quality checks.
3. Transform data and load it into a SQL database.
4. Add tests and automated pipeline checks.
5. Document the workflow, decisions, and outcomes.
